This project is a menu-driven calculator built in C language that performs basic arithmetic operations using:

User Defined Functions (UDF)

Switch Case

Looping

Endless execution until exit command

The program allows the user to choose an arithmetic operation and perform calculations repeatedly until the user selects 0 (Exit).

🚀 Features

Addition (+)

Subtraction (-)

Multiplication (*)

Division (/)

Modulo (%)

Runs continuously using loops

Clean switch-case-based menu

User-friendly experience



Press 1 for +
Press 2 for -
Press 3 for *
Press 4 for /
Press 5 for %
Press 0 for Exit




🧠 How It Works

Program displays a menu

User selects an option

Two numbers are taken as input

Corresponding UDF (function) is executed

Result is displayed

Menu appears again until user presses 0

🛠 Tech Stack

Language: C

Compiler: GCC / MinGW / Turbo C / VS Code
