About this Repository:
This repository contains C language programs and practice exercises that I’ve written while learning the fundamentals of programming. 
The main focus is on understanding the core concepts of C such as variables, data types, operators, control statements, loops, arrays, functions, and pointers.
Each program is simple and well-commented to make it easier for beginners to follow and learn.

C is one of the most powerful and efficient programming languages, widely used for system programming, operating systems, and embedded systems. Through this repository,
I aim to strengthen my logic building, problem-solving skills, and get a solid foundation for learning other languages like C++, Java, and Python in the future.
